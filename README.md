# UrbanMart

Live website link: https://urban-mart-demo.netlify.app/

UrbanMart is a responsive e-commerce product showcase website built with **React** and **Chakra UI**. This project demonstrates modern web development features such as **dynamic filtering, debounced search, and responsive design**.

## Features

- **Category Filtering:** Browse products by category in real-time.
- **Price Slider Filtering:** Interactive slider to filter products by maximum price.
- **Debounced Search:** Search products by title without lag, thanks to debouncing.
- **Responsive Grid Layout:** Product grid adapts seamlessly to mobile, tablet, and desktop screens.
- **Interactive Product Cards:** Each card displays an image, title, description, and price.
- **Sticky Navbar:** Navigation bar stays at the top while scrolling.
- **Clean UI:** Built using Chakra UI for modern, consistent styling.

## Tech Stack

- **Frontend:** React, Chakra UI
- **Icons:** React Icons (`FaDollarSign`)
- **API:** [Fake Store API](https://fakestoreapi.com/)
- **State Management:** React `useState` & `useEffect` hooks
- **Styling:** Chakra UI components and responsive props

## Development

```bash

```
